# teleru

**teleru** — это полностью локализованная на русский язык сборка клиента [tele](https://github.com/nitreojs/tele) (продвинутого форка Telegram Desktop), синхронизированная с актуальной версией Telegram Desktop **v7.3.1** и Tele **v7.3.1-tele.22**.

Репозиторий содержит полную инфраструктуру автоматизированной локализации, строгого аудита строк, грамматической плюрализации и безопасного механизма обновлений с проверкой Ed25519-подписей.

---

## Загрузка и установка

Готовые релизы доступны на странице [Релизы teleru](https://github.com/Duerotator/teleru/releases/latest).

- **Windows x64**: `tele-<version>-win64.zip`  
  Распакуйте архив в любую удобную папку и запустите `tele.exe`. Программа работает в портабельном режиме и хранит все свои данные в подпапке `tdata` рядом с исполняемым файлом, никак не затрагивая установленный официальный Telegram Desktop.
- **Linux x64**: `tele-<version>-linux64.zip`  
  Распакуйте архив (например, в `~/.local/opt/tele`) и запустите бинарник `./tele`. Приложение сохраняет данные профиля в `~/.local/share/tele` и автоматически регистрируется в системном меню.
- **macOS** (Apple Silicon и Intel): `tele-<version>-macos.dmg`  
  Откройте DMG-образ, перетащите `tele` в папку «Программы». Так как бинарник не нотариализован Apple, перед первым запуском выполните в терминале команду снятия карантина:
  ```bash
  xattr -dr com.apple.quarantine /Applications/tele.app
  ```
  Данные сохраняются в каталоге `~/Library/Application Support/tele`.

## Ключевые возможности

Все функции `tele` удобно сгруппированы в отдельном меню: **Настройки → tele**, прямо под выбором языка интерфейса. Меню разбито на логические разделы с поддержкой мгновенного поиска по ключевым словам.

### 🛡 Приватность и скрытый режим
- **Режим невидимки (Ghost Mode)**: возможность читать сообщения без отправки серверных отметок о прочтении, скрывать индикатор набора текста («печатает…») и статус активности.
- **Подсмотр последнего захода (Peek Last Seen)**: временный просмотр скрытого статуса собеседника без постоянного раскрытия своего времени активности.
- **Локальный пароль для защиты операций**: запрос локального PIN-кода перед отправкой, конвертацией, передачей или улучшением подарков, покупкой платных медиа и звёзд.
- **Сохранение удалённых сообщений и тем**: локальное хранение удалённых сообщений и тем форумов с историей редактирования, защищённое шифрованием.
- **Режим стримера**: скрытие номеров телефонов, аватарок и текста всплывающих уведомлений при демонстрации экрана или записи видео.

### 🎨 Интерфейс и кастомизация
- **Редактор контекстных меню**: визуальная настройка структуры контекстных меню сообщений, чатов, папок и профилей с поддержкой подменю, разделителей и пресетов.
- **Тонкая настройка масштаба**: регулировка масштабирования интерфейса с шагом в 1%.
- **Компактный список чатов**: скрытие превью текста сообщений, скрытие счётчиков непрочитанных на вкладках и в трее.
- **Настройка заголовка окна**: поддержка динамических шаблонов названия окна (`{chat} – tele`, `tele #{build}` или произвольных переменных).
- **Меньше движения (Reduce Motion)**: отключение циклических анимаций стикеров, реакций и эффектов сообщений без влияния на системные настройки.

### 💬 Сообщения и работа с медиа
- **Прикрепление медиа над полем ввода**: компоновка альбомов, упорядочивание и редактирование медиа прямо над полем набора текста без открытия всплывающих окон.
- **Аудио как голосовые сообщения**: отправка любого аудиофайла (`.mp3`, `.ogg`, `.flac`) в виде голосового сообщения со сгенерированной звуковой волной.
- **Цитаты и форматирование**: цитирование блоков форматированного текста без потери разметки, нумерация строк в длинных блоках исходного кода.
- **Быстрый просмотр текстовых файлов**: открытие файлов `.txt`, `.json`, `.csv` и исходного кода прямо во встроенном просмотрщике tele.
- **Подтверждение перед отправкой**: защита от случайной отправки стикеров, GIF и голосовых сообщений.
- **Быстрое закрытие медиа**: закрытие просмотрщика фотографий и видео аппаратной кнопкой «Назад» на мыши.

### 🎁 Подарки и Студия Подарков (Gift Studio)
- **Студия подарков**: полноценный конструктор коллекционных предметов из оригинальных моделей, фонов и символов с экспортом в PNG, MP4, GIF или валидные стикеры TGS.
- **Симуляция прокачки подарков (Fake Upgrades)**: визуальная симуляция процесса улучшения подарка с оригинальной рулеткой редкостей без реальных трат звёзд Telegram.
- **Конструктор сетки профиля (Gift Grid Builder)**: составление и сохранение красивых витрин подарков с эксклюзивными рамками и экспортом изображений.
- **Массовые операции и фильтрация**: поиск подарков в профиле по модели, символу или номеру, массовая передача, скрытие или выставление на витрину.
- **Экспорт транзакций**: подробный поиск, фильтрация по датам и экспорт транзакций Звёзд и TON в формат CSV.

### 🛠 Инструменты разработчика
- **Встроенная MTProto-консоль** (`Ctrl+Alt+M`): выполнение любых методов API Telegram в JSON/JSON5 с подсказками схемы, автодополнением и инспектором результатов.
- **Просмотр TL-схем (View as TL)**: просмотр сырых структур объектов Telegram непосредственно в интерфейсе клиента.
- **Отображение дата-центров (DC)**: показ номера дата-центра для чатов, профилей и загруженных медиафайлов.

## Особенности русской сборки (teleru)

1. **100% покрытие перевода**:
   - Полная локализация всех страниц настроек, контекстных меню, диалогов, консольных инструментов и сообщений об ошибках.
   - Автоматический аудит в CI валидирует 3492 строковых вхождения перед каждой сборкой. Сборка немедленно блокируется, если в upstream появляются непереведённые или изменённые строки.

2. **Корректная плюрализация (русские формы множественного числа)**:
   - В ядро клиента интегрирован модуль `tele_russian_plural.h`, поддерживающий грамматические правила русского языка (1 настройка, 2 настройки, 5 настроек) вместо простого английского суффикса `-s`.

3. **Безопасные подписанные обновления**:
   - В клиент встроен механизм фоновых обновлений через GitHub Releases с криптографической проверкой подписи Ed25519 (`ci/update-public-key.pem`).
   - Исключена возможность установки повреждённых или сторонних сборок: проверяются SHA-256 хеши каждого файла и архива.

## Сборка из исходников и участие в разработке

Сборка базируется на чистых исходниках Telegram Desktop с наложением очереди патчей tele и каталога локализации `teleru`.

### Требования
- Python 3.11+
- Node.js 18+
- Git

### Быстрый старт
```powershell
# 1. Проверить зафиксированную версию upstream
python ci/upstream.py version

# 2. Установить зависимости CI
npm ci --prefix ci --ignore-scripts
python -m pip install -r ci/requirements.txt

# 3. Запустить тестовый набор
python -m unittest discover -s ci/tests -v

# 4. Проверить полноту перевода относительно чистых исходников tdesktop
python ci/localization.py C:\path\to\tdesktop
```
