# AGENTS.md

Instructions for AI coding agents working on **teleru**.

`teleru` maintains the Russian localization, pluralization overlay, and automated release pipeline for `tele` (Telegram Desktop fork).

---

## Hard Rules

1. **Upstream Version Lock (`TELE_UPSTREAM.json`)**:
   - `TELE_UPSTREAM.json` pins the exact upstream tag, full commit SHA, and tdesktop base version. Never edit or desynchronize this file unless performing an explicit upstream update via `ci/upstream.py update`.

2. **Zero Missing Strings (100% Localization Coverage)**:
   - Any modification or upstream synchronization must pass `python ci/localization.py <tdesktop>` with **100.00% coverage**, **0 missing**, and **0 invalid** occurrences.
   - New options (`kOption...`) must have both `name` and `desc` localized in `i18n/ru/new-options.json` with exact matching `source`.

3. **Placeholder & Format Integrity**:
   - Every format specifier (`%1`, `%2`, `%L1`, `%n`, `%%`) must be preserved in translations without alteration.
   - Use correct Russian typography: guillemets («...») and inner quotes („...“).

4. **Window Title Templates**:
   - Do not inject artificial Cyrillic title overrides (such as «ТЕЛЕ #x»). Upstream title formatting (`tele #{build}`, `{chat} – tele`) is preserved directly.

5. **Russian Pluralization Helper**:
   - Pluralization changes for Russian noun forms must route through `Tele::RussianPluralIndex` in `tele/tele_russian_plural.h` (generated by `ci/teleru_overlay.py`).

6. **All Unit Tests Must Pass**:
   - Run `python -m unittest discover -s ci/tests -v` before committing any changes. All tests must pass with exit code 0.

7. **Line Endings & Git Cleanliness**:
   - Preserve line endings of modified files (CRLF where existing, LF where existing).
   - Never commit private keys (`*.pem`), `.agents/` directories, `.local/`, or temporary localization reports (`localization-report.json`, `localization-inventory.json`).

8. **Commit Message Conventions**:
   - Single-line conventional commit messages: `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`. No multi-line bodies, AI trailers, or tool attribution.

---

## Verification Commands

```powershell
# Run the complete test suite
python -m unittest discover -s ci/tests -v

# Audit localization against patched Telegram Desktop sources
python ci/localization.py C:\Users\user\test_tdesktop

# Verify overlay application idempotency
python ci/translate_ru.py C:\Users\user\test_tdesktop --inventory localization-inventory.json
```
